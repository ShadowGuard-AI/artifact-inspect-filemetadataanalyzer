artifact-inspect-filemetadataanalyzer

The Bin Card. Analyzes file metadata (creation date, modification date, owner, permissions, and more) and flags anomalies based on heuristic rules or user-defined thresholds, using the os and stat modules.

The repository main.py

Usage

./artifact-inspect-filemetadataanalyzer [params]
ParameterWhat it does
-hShow help message and exit.
-tThreshold in days for flagging old dates. Defaults to 30 days.
-oExpected owner of the file. Flags if different.
-pExpected permissions. The entry in the source breaks off after the opening of an example, at the words "e.g." with nothing following; no example value is guessed here.
--pe_checkPerform additional checks if the file is a PE executable.

What the card records

Every inspected file gets the keeper's reading: its dates, its owner, and its permissions, checked against the threshold and any expected values given on the command line. The declared dependencies are python-magic and pefile, alongside the standard library's os and stat.

Stated limits

  • The modification date is always checked. The creation date is checked only where the platform provides a real birth time (st_birthtime, for example on macOS).
  • On Linux there is no birth time in os.stat, and st_ctime is a change time, not a birth time, so no creation age is checked there; the change date is printed under its own name.
  • The tool inspects any file's metadata. Only the --pe_check addition is specific to PE executables.
